# Deploy guide — Rizz Edits Studio backend (100% free path)

The website is already live. This deploys the FastAPI backend so the contact
forms submit real inquiries. You need 4 free accounts (no card for any):
GitHub, Render, Neon, Resend.

## Step 1 — Push the code to GitHub (5 min)

```bash
cd rizz-edits-studio-backend
git init
git add .
git commit -m "Rizz Edits Studio API"
# create an empty repo on github.com, then:
git remote add origin https://github.com/YOURNAME/rizz-edits-studio-api.git
git push -u origin main
```

## Step 2 — Free Postgres at Neon (5 min)

1. Sign up at https://neon.tech (no card).
2. Create a project, copy the **connection string**.
   It looks like: `postgresql://user:pass@ep-xxx.neon.tech/dbname?sslmode=require`
3. The code needs `psycopg2-binary` for Postgres — it's already in
   `requirements.txt`. SQLAlchemy also accepts the `postgresql://` scheme
   directly, so paste the string as-is into `DATABASE_URL`.

## Step 3 — Free email at Resend (5 min)

1. Sign up at https://resend.com, create an **API key**.
2. For testing you can use Resend's default sender. For production, verify
   your own domain in Resend and set it as `RESEND_FROM`.

## Step 4 — Deploy the API on Render (10 min)

1. Sign up at https://render.com, **New → Web Service**, connect your GitHub repo.
2. Render auto-detects `render.yaml`. Set these env vars in the dashboard:
   - `DATABASE_URL` → the Neon connection string from Step 2
   - `ALLOWED_ORIGINS` → your live site URL, e.g.
     `https://muse.ai/s/rizz-edits-studio-ai-automation-xpxk6zzs0yxpxo5`
     (comma-separated if more than one)
   - `RESEND_API_KEY` → from Step 3
   - `NOTIFY_TO` → your inbox, e.g. `you@gmail.com`
   - `RESEND_FROM` → verified sender (or leave empty for testing)
   - `ADMIN_API_KEY` → auto-generated by Render
3. Deploy. Your API will live at something like
   `https://rizz-edits-studio-api.onrender.com`.
4. Check `https://YOUR-API.onrender.com/api/health` → should return `{"ok": true}`.

**Free-tier realities (verified Oct 2026):**
- The service sleeps after 15 min idle; the first request after sleep takes
  ~30–60s (cold start). The site's form shows a loading state, so this is fine.
- Do NOT use Render's own free Postgres — it expires after 30 days and your
  data is deleted. Neon is the permanent free tier.

## Step 5 — Connect the site to the API (2 min)

Tell Muse (me) your Render API URL. I will set `window.RIZZ_API_BASE` on the
live site to it via an edit — no code changes needed from you. From that
moment, form submissions POST to `/api/inquiries` for real, with the
in-browser brief composer as automatic fallback if the API is unreachable.

## Step 6 — Verify end to end

1. Submit the Contact form on the live site.
2. You should get the success panel AND an email at `NOTIFY_TO`.
3. Check the saved row: `curl -H "X-API-Key: <ADMIN_API_KEY>" https://YOUR-API.onrender.com/api/inquiries`
